# Mobile Font Readability

## Goal

Make the review flow's text comfortable to read on mobile without changing its compact layout or visual identity.

## Design

Increase the font sizes of the smallest interface text on mobile: helper and draft metadata to about 12–13px, labels and buttons to about 14–15px, and the business name to 18px. Keep star sizes and the existing layout unchanged. Apply the adjustments at the mobile breakpoint so desktop styling remains as-is.

## Validation

Check the page at a mobile viewport and verify labels, review cards, platform buttons, and helper text are easier to read without horizontal overflow or crowded controls.
